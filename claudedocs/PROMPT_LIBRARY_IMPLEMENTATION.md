## 🚀 使い方

### 基本操作
1. **プロンプト作成**: 右上の「新規作成」ボタン
2. **検索**: 上部の検索バーでリアルタイム検索
3. **カテゴリー選択**: 左サイドバーから選択
4. **編集**: リストからプロンプトをクリック
5. **最適化**: エディター内の「AI最適化」ボタン
6. **適用**: エディター下部の「このプロンプトを適用」ボタン

### ショートカット（予定）
- `Ctrl+N`: 新規プロンプト
- `Ctrl+S`: 保存
- `Ctrl+F`: 検索フォーカス
- `Ctrl+O`: プロンプト最適化
